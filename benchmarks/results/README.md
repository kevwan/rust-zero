# Raw results

Store immutable JSON output in a host/date directory using `<framework>-run<N>.json` and include a
matching Markdown hardware record. Each accepted baseline contains at least five post-warm-up raw
runs per framework plus the deterministic `baseline-summary.json` generated by `compare.py`.

The initial cross-framework baseline is in `v1-m3-max-2026-08-14/`. Absolute results must only be
compared with later runs on the recorded host configuration; other machines should create their own
directory and baseline.

Soak campaigns use `soak-<architecture>-<date>/`, retain the exact TOML configuration, raw JSON,
hardware record, start/end UTC timestamps, and an operator summary of any interruption. Results
shorter than the gates in `STABILIZATION.md` are labeled `smoke` and never count as alpha-exit
evidence.
